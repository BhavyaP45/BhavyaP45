# Add Forest to your GitHub profile

Upload the contents of this folder into the root of `BhavyaP45/BhavyaP45`. Keep `README.md`, `assets/`, `scripts/`, and `.github/` at that level. The header and stats are images; the rest is ordinary GitHub Markdown.

The activity card ships with the 214 contributions shown on your personal website on September 30, 2026. The included GitHub Actions workflow refreshes it daily using GitHub's contribution calendar. You can run **Actions → Refresh profile activity → Run workflow** after uploading. It uses the repository's built-in `GITHUB_TOKEN`; no personal access token or external stats service is required.

GitHub must allow Actions for the repository, and its rules must allow this workflow to push an update. If pushes are blocked, the existing card stays visible with its last update date.

The dark banner is fixed artwork. The surrounding README follows the visitor's GitHub theme. GitHub may show the project table differently from the concept preview, especially on small screens.

`SETUP.md` is for you; you can leave it out of the repository.
